Keys belong to a universe $U=0,\dots, u-1$ with size $u = 2^w$.
Keys are $S \subset U$ with $n=|S|$, with function $h: U \rightarrow \{0,\dots,m-1\}$.
We want $A[h(x)] = x$.

We use hash functions so not to have an array of size $u$. This introduces **collisions**, when $h(x) = h(y)$ for different $x$ and $y$. We assume separate chaining for this lecture.

**Desired properties:**
- Keys are spread out so we don’t have many collisions
- $m=O(n)$
- $h$ is fast to compute

**Claim:** for any $h$, if $u \geq (n-1)m+1$, there exists $n$ items that hash to the same location.

**Proof:** contrapositive. If every location had at most $n-1$ items, then $U$ could have size at most $m(n-1)$.

## Universal Hashing

> [!definition]
> A set $H$ where each $h \in H$ maps $U \rightarrow \{0,\dots,m-1\}$ is called **universal** if for all $x \neq y$ in $U$, we have:
> $$\Pr_{h \in H} [h(x) = h(y)] \leq \frac{1}{m}$$

Alternative way of defining: count the number of hash functions in $H$ that cause $x$ and $y$ to collide.
$$\frac{|\{h \in H | h(x) = h(y)\}|}{|H|} \leq \frac{1}{m}$$
In the case of the following example there exists a pair with probability greater than $\frac{1}{m}$, namely, $(a,b)$.

| Pair     | $h_1$ | $h_2$ | $h_3$ | $\Pr[\text{collision}]$ |
| -------- | ----- | ----- | ----- | ----------------------- |
| $(a, b)$ | ✓     | ✓     | ✗     | **2/3**                 |
| $(a, c)$ | ✗     | ✗     | ✓     | 1/3                     |
| $(b, c)$ | ✗     | ✗     | ✗     | 0                       |
> [!theorem]
> If $H$ is universal, then for any set of keys we’re maintaining of size $n$ and for any key $x$, if an $h$ is drawn randomly from $H$, the **expected** number of collisions between $x$ and other keys is less than $\frac{n}{m}$

$\alpha = \frac{n}{m}$ is the **load factor** of the hash table.

### Constructing family with matrix method

Assume that keys are $w$-bits long, $U=0,\dots,2^w-1$ and that the table size is $m=2^b$, i.e., a power of $2$.

We build a matrix $A$ with $w$ columns and $b$ rows with random values. 

Then $h(x)=Ax$, we do dot product with addition $\mod 2$. This effectively squashes a $w$-bit key into a $b$-bit index.

**Proof this is universal:**

Take keys $x \neq y$. They must differ somewhere, say in bit $i$. Now imagine we preset everything in $A$ except the $i$th column. Say $x_i=0$ and $y_i=1$.

Notice that $Ax$ is just adding up columns of $A$ where $x$ has a $1$. So column $i$ is not used for $x$ and $h(x)$ is fully determined since the rest of $A$ was preset.

Now for $h(y)$, column $i$ counts, so each bit in column $i$ can change the matching bit in $h(y)$. That means each of the $2^b$ possible outputs of $A$ will yield a different $h(y)$ and hence $P[h(x)=h(y)]=\frac{1}{2^b}=\frac{1}{m}$.

### On randomness of universal hashing

Sometimes universal hashing doesn’t do anything to prevent hashes of different keys from correlating.

>[!definition] Pairwise independece
> If for all pairs of distinct keys $x_1, x_2 \in U$ and every pair of values $v_{1}, v_{2} \in \{0, \dots, m-1\}$ we have:
> $$Pr_{h \in H}\left[ h(x_{1})=v_{1} \text{ and } h(x_{2})=v_{2}\right]=\frac{1}{m^2}$$

In other words, if an adversary discovers the value of one key, it can’t deduce anything about the others. We can extend the concept to $k$-wise instead of pairwise.

## Perfect Hashing

We say a hash function is perfect for $S$ if lookups involve $O(1)$ deterministic cost.

#### Method 1: an $O(n^2)$-space solution

Let $H$ be universal and $m=n^2$. Then:
$$Pr(\text{exists a collision}) \leq {n \choose 2}\frac{1}{m}=\frac{n(n-1)}{2m}\leq \frac{n^2}{2n^2}=\frac{1}{2}$$
#### Method 2: an $O(n)$-space solution

- Hash into a table $A$ of size $n$ using universal hashing
- We will rehash each chain using the first method, squaring the size of the bin to get no collisions

We end up with table $A$ and chains $A_{1}, \dots, A_{n}$ and functions $h$ and $h_{1}, \dots, h_{n}$. We do $i=h(x)$ and then do $A_i[h_{i}(x)]$.

Hashing $L_i$ keys of $S$ into location $i$ so total space is $\text{space}=\sum_{i}(L_{i})^2$.

**Claim:** $Pr[\text{space} > 4n] < \frac{1}{2}$.
**Proof:**
We prove $\mathbb{E}[\text{space}] < 2n$ and this yields what we want by Markov’s inequality.
We count space by counting the number of ordered pairs that collide.
$$
\begin{align}
\mathbb{E}[\text{space}]&=\mathbb{E}\left[ \sum_{x}\sum_{y}C_{x,y} \right] \\
&=n + \sum_{x}\sum_{y \neq x}\mathbb{E}[C_{x,y}] \\
&\leq n + \frac{n(n-1)}{m} \\
&\leq 2n
\end{align}
$$
Note we move the case for $x=y$ out of the summation ($n$) since we **are** counting collisions of repeated elements.

Then we use the fact the $\frac{1}{m}$ probability for the expectation of indicator random variable and count the possible pairs: $n$ choices for $x$ and $(n-1)$ for $y$.
