## Random primes

We can pick a $\log M + 1$ bit string which will give us a number $\leq M$ with probability $\frac{1}{2}$.

##### How many primes in the set $\{1,2,\dots, n\}$
Let there be $\pi(n)$ primes in the interval.
$$
\pi(n) > \frac{n}{\log_{2} n}
$$
- So random $p$ is prime with probability at least $\frac{\pi(n)}{n} = \frac{1}{\log_{2}n}$

> [!corollary]
> If we want $k \geq 4$ primes, it suffices to pick $n\geq 2k\log_{2}k$

## String equality

Alice receives $N$-bit string $x$
Bob receives $N$-bit string $y$

They want to check $y=x$ without sending the whole $N$ bits!

- We want that if $x=y$ then $Pr[\text{Bob says equal}]=1$
- Also if $x \neq y$ then $Pr[\text{Bob says equal}] \leq \delta$

>[!algorithm]
>1. Alice picks a prime $p$ from $\{1, \dots, M\}$ for $M=200N \cdot \log_{2}(100N)$
>2. Sends Bob $p$ and also $x \mod p$
>3. Bob checks if $x \equiv y \mod{p}$

We never fail to verify equality.
But if $x \neq y$ then $Pr[\text{Bob says equal}] \leq 0.01$

*Proof*.
Define $D=(x-y)$. We say they are equal when $D = 0 \mod{p}$ so when $p$ divides $D$.
Since $x \neq y$, $D=p_{1}\dots p_{k}$ with $p_{i} \geq 2$ so $p_{1}\dots p_{k} \geq 2^k$ and since $D \leq 2^N$, $k \leq N$. 
We have at most $N$ divisors. The probability $p$ is one of them:
$$\frac{N}{\pi(M)}=\frac{N}{100N}=0.01$$
**Complexity:**
We have to send $p$ and $x \mod p$ which are both $\log_{2}M=\log_{2}(200N \log_{2} 100N) \in O(\log N)$.

#### Reducing error

1. Have Alice repeat the process multiple times independently, probability decreases exponentially since independent.

If we want probability of error $\delta$ then we must try $R=\log_{100}\left( \frac{1}{\delta} \right)$ 
It will cost $O(\log\left( \frac{1}{\delta} \right) \log N)$

2.  Alice chooses from a larger set. We want $k=sN$ primes from $2sN\log_{2}(sN)$ numbers so the probability the prime divides $D$ is $\frac{N}{sN}$. For $\delta = \frac{1}{10^6}$ we pick $s=10^6$.

It will cost:
$$
\begin{align}
&=2\log_{2}(2sN\log_{2}(sN)) \\
&=2\log_{2}s + 2\log_{2}N + 2\log_{2}(\log_{2}(sN))+2 \\
&=O(\log s + \log N)
\end{align}
$$
## Pattern matching

We get from some alphabet $\Sigma$, here we use $\{0, 1\}$
- text $T$ of length $n$
- pattern $P$ of length $m$
And want to output the locations of all occurrences of $P$ inside $T$

#### Karp-Rabin

We choose random $p$ to do $x \mod{p}$.

1. Drop the leftmost bit of $x$
	Equivalent to subtracting $x_{h} \cdot 2^{m-1}$ where $x_h$ is the bit
2. Multiply all by two, shift all bits to the left
3. Add a bit $x'_{l}$

New string: $x'=2(x-x_{h} \cdot 2^{m-1}) + x'_{l}$

Properties of modulo:
- $h_{p}(a+b)=(h_{p}(a) + h_{p}(b)) \mod{p}$
- $h_{p}(2a)=2h_{p}(a) \mod{p}$

Hence we just do $2(x-x_{h} \cdot 2^{m-1}) + x'_{l} \mod{p}$

```pseudo
KarpRabin():
	pick p in [1, ..., 2*s*m*log(sm)]
	
	compute h(P) and h(2^m)
	compute h(T[0..m-1])
	check if equal with h(P) and print match at 0 if yes
	
	for each i in [0..n-m-1]
		compute h(T[i+1..i+m]) using the previous hash
		if equal, print match at i+1
```

We will never miss a match
Might say match when there is no match in case of hash collision

We do $n-m$ comparisons each with $\frac{1}{s}$ probability of failure, hence $\leq \frac{n}{s}$ failure overall. Setting $s=100n$ gives $\delta=0.01$.
