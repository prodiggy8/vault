Definition of vector-valued function derivative:
$$r'(t) = \lim_{ \Delta t \to 0 } \frac{r(t+ \Delta t)-r(t)}{\Delta t}$$
>[!definition] Theorem
> If $r(t)=f(t)i + g(t)j + h(t)k$ then $r’(t)=f’(t)i + g’(t)j + h’(t)k$

Properties:
$$
\begin{align}
\frac{d}{dt}[f(t)u(t)]=f'(t)u(t) + f(t)u'(t) && \text{Scalar product} \\
\frac{d}{dt}[r(t) \cdot u(t)] = r'(t) \cdot u(t) + r(t) \cdot u'(t) && \text{Dot product} \\
\frac{d}{dt}[r(t) \times u(t)] = r'(t) \times u(t) + r(t) \times u'(t) && \text{Cross product} \\
\frac{d}{dt}[r(f(t))]=r'(f(t)) f'(t) && \text{Chain rule}
\end{align}
$$

$$
\begin{align}
r(t)=(6t+8)i + (4t^2+2t-3)j+5tk \\
u(t)=(t^2-3)i+(2t+4)j +(t^3-3t)k
\end{align}
$$

	$=r'(t) \cdot u(t) + r(t) \cdot u'(t)$

## Tangent vectors

> [!definition] Tangent
> A tangent vector $v$ at $t=t_{0}$ is any vector such that when the tail of the vector is placed at point $r(t_{0})$, vector $v$ is tangent to the curve. We can furthermore define the principal unit tangent vector as:
> $$T(t)=\frac{r'(t)}{|r'(t)|}$$

## Integrals

$$\int \left[f(t)i + g(t)j + h(t)k \right] dt=\left[ \int f(t) dt \right]i + \left[ \int g(t)dt \right]j + \left[ \int h(t)dt \right]k$$
For indefinite integrals, **each component’s integral includes an integration constant**.
$$\int f(t)dt = F(t) + C_{1}$$
$$\int r(t)dt = F(t)i + G(t)j + H(t)k + C_{1}i + C_{2}j + C_{3}k=F(t)i + G(t)j + H(t)k + C$$
With $C=\langle C_{1}, C_{2}, C_{3}  \rangle$.
