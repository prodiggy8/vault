> [!definition] Vector-valued function
> $$r(t) = f(t)i + g(t)j + h(t)k$$
> Where the component functions $f$, $g$, and $h$ are real-valued functions of $t$. Also written as:
> $$r(t) = \langle f(t), g(t), h(t) \rangle $$

a)
$r(t)=4\cos ti+3\sin tj$
	$r(0) = \langle 4, 0, 0  \rangle$
	$r\left( \frac{\pi}{2} \right)=\langle 0, 3, 0 \rangle$
	$r\left( \frac{2\pi}{3} \right)=-2i+\frac{3\sqrt{ 3 }}{2}j$
	
b)
$r(t)=3\tan ti + 4\sec tj + 5tk$
	$r(0)=\langle 0, 4, 0 \rangle$
	Undefined
	$r\left( \frac{2\pi}{3} \right)=-3\sqrt{ 3 }i -8j + \frac{10\pi}{3}k$

c)
$r(t)=(t^2-3t)i + (4t+1)j$
	$r(0) = j$
	$r(1)=-2i + 5j$
	$r(-4)=28i - 15j$

For graphing these functions, **use a table**.

> [!definition] Limit of vector-valued function
> $$
> \lim_{ t \to a } r(t) = \left[ \lim_{ t \to a } f(t) \right]i + \left[ \lim_{ t \to a } g(t) \right]j + \left[ \lim_{ t \to a } h(t) \right]k
> $$
> Provided the intermediate limits exist.

a)
$r(t) = (t^2-3t+4)i + (4t+3)j$
	$\lim_{ t \to a } r(t) = 4i + 15j$

b)
$r(t)=\frac{2t-4}{t+1}i + \frac{t}{t^2+1}j + (4t-3)k$
	$\lim_{ t \to 3 }r(t)=\frac{1}{2}i + \frac{3}{10}j + 9k$

c)
$r(t)=\sqrt{ t^2 - 3t -1 }i + (4t+3)j + \sin \frac{(t+1)\pi}{2}k$
	$\lim_{ t \to -2 }= 3i -5j - k$

Continuity for $r(t)$ is defined at point $t=a$ if:
1. $r(a)$ exists
2. $\lim_{ t \to a }r(t)$ exists
3. $\lim_{ t \to a } r(t) = r(a)$
