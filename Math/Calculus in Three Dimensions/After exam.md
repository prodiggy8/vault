### Functions of several variables

$$f(x,y) \text{ maps each ordered pair } (x,y) \text{ in a subset } D \text{ of the real plane } \mathbb{R}^2 \text{ to a unique real number } z\text{.}$$
- $D$ is the domain of such function
- How to find the **range** of such a function?

**We find a solution to the equation $f(x,y)=z$.** 
Consider the example $f(x,y)=3x+5y+2$.
1. Set $y=0$.
2. It yields $3x+2=z$. Rearrange to $x=\frac{z-2}{3}$.
3. Hence $\left( \frac{z-2}{3}, 0 \right)$ is a solution to this equation for any value of $z$.
4. Hence the range is all real numbers, $\mathbb{R}$.

**Checkpoint 4.1**
find domain and range of function $\sqrt{ 36-9x^2-9y^2 }=\sqrt{ 36-9(x^2+y^2)}=3\sqrt{ 4-x^2-y^2 }$

Domain: all real numbers such that $x^2+y^2 \leq 4$.
We plug in the original function:
$4-x^2+y^2$ ranges over $[0,4]$.
$\sqrt{ t }$ is increasing so it fully maps $[0,4]$ to $[0,2]$.
$3\sqrt{ t }$ then will just map it to $[0,6]$.
Hence the range is $[0,6]$.

# How to graph them?

With a function of two variables, each ordered pair $(x,y)$ in the domain is mapped to a real $z$. Therefore the graph is ordered triples $(x,y,z)$.

The graph of a function $z=(x,y)$ of two variables is called a **surface**.
